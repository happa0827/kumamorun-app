# キャラクターを守るため、デモ版を作り、完全版の画像はサーバーから承認された端末にだけ配る

オリジナルのキャラクターを守りたい。リポジトリ（アプリとサイトの両方）は PUBLIC で、キャラクターの画像はアプリに同梱されていた。インストーラーを開けば誰でも取り出せる。
そこで、承認していない人が使うデモ版を作る。デモ版ではキャラクターをシルエットにし、進化・開花とスタート制限を止める。
承認はサイトで行い、承認されたアカウントの端末だけが、完全版の画像をサーバーから受け取る。計画は `docs/plan/demo-edition.md`。

## Considered Options

- **アプリの中で表示だけ切り替える**: いちばん簡単。だが、画像はアプリに入ったままなので、インストーラーから取り出せる。守る目的を果たさない。
- **リポジトリを非公開にする**: ソースからは見えなくなるが、インストーラーには画像が残る。自動更新は GitHub Releases の公開 URL を読んでいるので、配る先も作り直しになる。
- **画像をサーバーから配る（採用）**: アプリとリポジトリには、シルエットだけを入れる。完全版の画像は Workers KV に置き（R2 は支払い情報が要るため）、承認されたアカウントのトークンでだけ返す。

## Consequences

- 版を決めるのはサーバー。アプリは `GET /sync` の `edition` を見て、端末に控える。`"full"` 以外（欠けている場合を含む）はデモ版。アプリだけを先に出すと既存の利用者がデモ版になるので、サイトを先に出す。
- 端末の控えを書き換えればスタート制限は使えるようになるが、画像と進化はサーバーが止めるので、守りたいものは守れる。
- 既存のアカウントは、移行で全員を承認済みにする（「今使っている人は完全版のまま」）。2026-11-15 の切り替えで全員がサイトに登録したので、アカウントを対象にすれば漏れはない。
- 版のない古い保存ファイルはデモ版として読む。既存の利用者も、更新後の最初の同期まではシルエットになる。
- デモ版でたまった成功日の進化は、捨てずに保留のまま残す。承認されたら、まとめて反映される。
- ログアウトとトークンの失効、承認の取り消しでは、デモ版に戻り、受け取った画像を端末から消す。
- 2.6.5 までに配ったインストーラー、git の履歴、Electron 版には画像が残る。これまでに配った分は守れない。アイコンにもキャラクターの絵が残る。
  この ADR で守るのは、**これから先に広がる分**だけと割り切る。履歴の書き換え（`git filter-repo` と force push）は、PR の参照が残って中途半端になり、元にも戻せないので行わない。
  代わりに v3.0.0 で、リポジトリを履歴なしで作り直した。古いリポジトリは `kumamorun-app-archive` に改名して非公開にし、履歴・タグ・PR・古いリリース・`electron` ブランチはそこに残した。手順は `docs/plan/repo-split.md`。
