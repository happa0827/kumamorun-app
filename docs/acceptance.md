# Windows 実機の受け入れチェック

Tauri 版を Electron 版の置き換えとして切り替える前に、Windows 実機で確かめる項目。
用語は GLOSSARY.md に従う。時刻に依存する項目は、Rust 側のテストで時刻を差し替えて自動で確かめ、
実機では OS が絡む部分だけを確かめる。

## 判定の分け方
- 自動: Rust のテストで確かめる。実機では扱わない。
- 実機: 画面、音、OS の挙動が絡むので、人が確かめる。

## 1. タイマー

| # | 場面 | 期待 | 確かめ方 |
|---|---|---|---|
| T1 | 遊びを時間切れまで続ける | 完走になり、休憩の猶予が3分始まる | 自動 |
| T2 | 休憩の猶予内に休憩を開始 | 失敗にならない | 自動 |
| T3 | 休憩の猶予を過ぎてから休憩を開始 | 失敗が1回付く | 自動 |
| T4 | 遊びの完走後、休憩を開始せず放置 | 失敗にならない（現行の挙動を維持） | 自動 |
| T5 | 別画面（設定、履歴など）にいる間 | タイマーと制限時刻の監視が止まらない | 実機 |
| T6 | トレイに隠れている間 | 時間どおりに鳴る | 実機 |

## 2. スタート制限

| # | 場面 | 期待 | 確かめ方 |
|---|---|---|---|
| R1 | 遊び中にスタート制限の時刻に達する | 遊びは打ち切りになり、遊び回数に数えない | 自動 |
| R2 | 昼休憩の開始時と終了時刻に、3分以内に「やめた」を押す | やめた確認が通り、失敗にならない | 自動 |
| R3 | やめた確認に3分以内に応答しない | 失敗が1回付く | 自動 |
| R4 | やめた確認の通知 | 画面と音で出る | 実機 |
| R5 | スタート制限の時間帯に遊びと休憩を開始する | 開始できない | 自動 |
| R6 | 平日と週末 | それぞれ別の設定が使われる | 自動 |
| R7 | 平日から週末（金曜→土曜、日曜→月曜）をまたぐ | 日付が変わる 0 時に、切り替わった設定で評価される | 自動 |
